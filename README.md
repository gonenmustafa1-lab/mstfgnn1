# Mustafa TV

Basit, mobil uyumlu Türkçe canlı TV arayüzü.

## GitHub Pages ile yayınlama
1. Bu klasördeki `index.html`, `style.css` ve `script.js` dosyalarını deponun ana dizinine yükleyin.
2. GitHub deposunda **Settings → Pages** bölümünü açın.
3. **Deploy from a branch** seçin, branch olarak `main`, klasör olarak `/ (root)` seçin ve **Save**'e basın.
4. Site adresi `https://gonenmustafa1-lab.github.io/mstfgnn1/` olacaktır.

## Not
Yayın adresleri üçüncü taraf M3U listesinden alınır. Kaynaklar değişebilir, kapanabilir veya tarayıcı tarafından engellenebilir. Çalışacağı garanti edilemez. NOW TV için resmî canlı yayın bağlantısı yedek olarak gösterilir.
